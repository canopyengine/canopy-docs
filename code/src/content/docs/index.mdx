Canopy is an experimental Kotlin/JVM engine with a node tree, composable behaviors,
reactive values, terminal hosting and a separate headless host.

- [Documentation index](/manual/)
- [Installation](/manual/manuals/getting-started/installation/)
- [First project](/manual/manuals/getting-started/first-project/)
- [Architecture](/manual/engine-details/engine-architecture/)
- [Snapshot status](/manual/misc/releases/0.1.0/)

Desktop is currently excluded from the build. Graphical examples and the complete
ecosystem simulation remain planned work.
