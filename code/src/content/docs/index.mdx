## A young engine, growing in the open

Published installation uses **0.1.0-alpha.1**. Foundation-integration guides
identify pending 0.1.0 changes separately; they are not a stable release declaration.
Terminal and headless are enabled. Desktop is excluded; the aquarium onboarding
project and the complete ecosystem demo remain release workstreams.
